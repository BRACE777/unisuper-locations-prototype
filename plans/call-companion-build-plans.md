# Call companion: build plans

Five tools for taking member calls faster. All figures and rules come from the public PDS set issued 28 September 2026. Nothing here reads member data or connects to an internal system.

Written 12 November 2026. Nothing in this file is built yet.

## Decisions that apply to all five

| Decision | Choice | Why |
|---|---|---|
| Where the code lives | `companion/` in this folder | `build.js` only copies `index.html`, `css` and `js`, so nothing in `companion/` or `plans/` is published to GitHub Pages. |
| What you open at work | One file, `companion.html`, with data, script and styles inlined | Opens by double-click. No server, no install, no network. The maps prototype needs a server because it uses ES modules; this must not. |
| Calculators | Excel workbook with native formulas, no macros | Macro-free workbooks open on locked-down machines. |
| Source of truth | `companion/data/rates.json` (every threshold, with document, page and issue date) | The same figure appears in several documents. One table feeds the workbook, the lookup, the timeframes and the explainers. |
| Citations | Every answer carries document, issue date, page and a verbatim quote | You can quote the source on the call, and a reviewer can check each card against the PDS. |
| LLM use | At build time, to draft cards, aliases and explainers. Not at call time by default. | Lookups stay instant and offline, and nothing typed during a call leaves the machine. An optional "Ask" mode is planned in section 3 but is off by default. |
| Member data | None, ever | Inputs are typed and never saved. Internal processing times live in a git-ignored local file. |

### Shared groundwork (built once, before tools 2 to 5)

1. `companion/tools/fetch-sources.mjs` downloads the seven public PDFs (Flexi Pension PDS, Accumulation 1 PDS, Personal Account PDS, How super works, Fees and costs, Insurance in your super, How we invest your money) and records URL, issue date and file hash.
2. `companion/tools/extract-pages.mjs` runs `pdftotext -layout` and splits on page breaks into `data/pages.json` (document, page number, text). Already proven: the extracted text keeps page breaks (36 in the Flexi Pension PDS).
3. `data/rates.json` and `data/glossary.json` are drafted from the page text and checked by hand.
4. `companion/build.mjs` inlines everything into `companion/dist/companion.html`.

Two documents are not yet read: Insurance in your super, and How we invest your money. Both are needed for insurance rules and for switch timing.

## 1. Drawdown workbook (minimum and maximum)

**Recommendation:** build the Excel workbook, not a web calculator. It extends the sheet you already have, and the same formulas can be mirrored into the companion page later.

**File:** `companion/dist/Flexi Pension drawdown calculator.xlsx`, generated by `companion/tools/build_workbook.py` (openpyxl is installed) so the rates are never typed twice.

### Sheets

| Sheet | Contents |
|---|---|
| Calculator | Inputs: date of birth, start date, opening balance, pension type (Retirement Phase, TTR, Beneficiary), payment frequency. Outputs listed below. |
| Full table | One row per possible start date in the chosen financial year, one column per age band. Each cell is the pro-rata minimum per $100,000. Change the year in one cell and all 365 or 366 rows recalculate. |
| By balance | Balance ladder from $25,000 to $2.1 million against the seven age bands: full-year minimum, plus the TTR 10% maximum. |
| Closing a pension | Pro-rata minimum owed at a closure or commutation date, less payments already made. |
| Rates | Age-band percentages, TTR cap, rounding rule, $25,000 minimum, $6,000 residual, $10,000 close-out. Each with PDS page. |
| Checks | The three PDS worked examples as automatic PASS or FAIL cells. |

### Calculator outputs

- Age at start, age band and percentage.
- Days left in the financial year, counted from the start date inclusive.
- Full-year minimum and pro-rata minimum, rounded to the nearest $10.
- TTR maximum: 10% of the opening balance, not pro-rated.
- The allowed range for the year.
- Payments remaining this year for the chosen frequency, and the amount per payment at the minimum, the maximum, or a chosen amount.
- A flag when the start date is in June (the member can choose no payment until the next year).
- Next 1 July: the age band that will apply, so you can warn of a step up at 65, 75, 80, 85, 90 or 95.

### Core formulas

- Financial year end: `DATE(YEAR(start)+(MONTH(start)>=7),6,30)`
- Days remaining: `FYend - start + 1`
- Days in year: `FYend - DATE(YEAR(FYend)-1,7,1) + 1`
- Pro-rata minimum: `ROUND(balance * pct * daysRemaining / daysInYear, -1)`

### Done when

- Gavin (67, starts 1 October 2026, $500,000) returns $18,700.
- Stacey (62, starts 1 July 2026, $300,000) returns $12,000 to $30,000.
- Bryn ($400,000 TTR from 1 April 2027 at the maximum) returns $13,330 a month.
- A balance under $25,000 and a start date outside the chosen year both show a clear warning.

### Open questions

- **Leap years.** The PDS example divides by 365 in a non-leap year. 2027-28 has 366 days. The workbook will use the real number of days; confirm against how the admin system calculates it.
- **Fortnightly cycle.** The PDS says "every second Friday" but not which Fridays. The workbook needs one known pay date as an input.
- **Payment cut-off dates** are not in the PDS and would be a typed input.
- **Your existing sheet** is not in this folder. Add it and the layout can match what you already use.

## 2. Forms finder, with directions to read out

**Goal:** type a few letters, get the right form and the exact words to guide the member to it.

### Data: `data/forms.json`

Built by `companion/tools/fetch-forms.mjs` from the public forms page. Checked today: the page is plain HTML and gives 45 PDF links and 36 "Complete online" links, covering 13 distinct online destinations.

Each form record holds:

- Title, summary, PDF link and size, and the online link where one exists.
- Group (super, pension, insurance, employer) and topic.
- **Say-this address:** the short address where the PDS gives one (`unisuper.com.au/forms`, `/pds`, `/combine`, `/tfn`, `/beneficiaries`, `/claims`, `/complaints`, `/insurance-calculator`, `/forms-insurance`, `/retirement-bonus`, `/join`). A short address is the fastest thing to read out.
- **Public site path:** the click path, such as Tools and learning, then Forms and documents, then Find by topic, then Contributions.
- **Online account path:** such as Manage account, then Notice of intent. Each path carries a `verified` flag.
- **Requirements** from the PDS: two adult witnesses for a paper binding nomination, an ATO form for a downsizer contribution, a notice of intent lodged before a pension starts.
- Search words, including what members actually say ("take money out", "change my bank").

### Screen

- Search box, with chips for super, pension, insurance, and online-only.
- Result card: title, online or PDF badge, the say-this address, numbered directions, requirements.
- Two copy buttons: the link, and the directions as plain text for a follow-up message.

### Refresh

Re-running the fetch script prints what was added, removed or renamed since last time, so the finder does not drift from the site.

### Done when

- Every form on the public page appears once, with a working link.
- "noi", "bank", "beneficiary", "rollover", "hardship" and "tfn" each return the right form first.
- Each card shows whether it is online, PDF, or both.

### Open questions

- **Online account menu labels.** The link addresses show the structure (`manage-account/notice-of-intent`, `profile/personal-details`, `pension/flexi-withdrawal`), and the PDS names four paths. The rest need you to confirm the labels, because the account area needs a login.
- **Forms that are phone-only** (the PDS names the death benefit application as available by calling) are added by hand.

## 3. Instant rule lookup with source

**Goal:** type "ttr max", "6000" or "noi deadline" and see a one-line answer with its PDS page, in under a tenth of a second.

### How it works without an LLM at call time

| Layer | What it does |
|---|---|
| Rule cards (`data/rules.json`) | About 150 cards. Each has the question, a one-line answer, detail, the figures, which products it applies to, any age condition, and the source with a verbatim quote. |
| Glossary (`data/glossary.json`) | Expands acronyms and member phrasing before searching. From the PDSs: TTR, BIS, DBD, SG, TFN, TPD, TSB, LISTO, FHSS, DASP, PPLSC, CGT, AFCA, TMD. Common shorthand: NOI, BDBN, TBC, CC, NCC, IP. A second file, `glossary.local.json`, holds your team's own shorthand and is git-ignored. |
| Context chips | Product (Accumulation 1, Personal Account, Retirement Phase, TTR, Beneficiary, DBD) and an optional age or date of birth. Cards that do not apply are hidden, and age-dependent cards show the row for that age. |
| Number matching | "6000", "6,000", "$6k" and "six thousand" all find the same cards. |
| Page search | If no card matches, a full-text search across every PDS page shows the best passages with document and page. |

Search is a small weighted scorer written inline: question and aliases weigh most, then tags, then answer text. No library is needed for 150 cards.

### Where the LLM is used

At build time, in a session like this one: drafting the cards, generating aliases and phrasings for each, and checking each card against its quoted source. The output is a static file that you review once.

### Optional "Ask" mode (off by default)

For questions no card covers, a local endpoint can answer from the PDS text.

- **Shape:** `companion/server.mjs` exposes `POST /ask`. The key stays on the server side, read from the environment, never in the page.
- **Request:** the question, the context chips, and the five best passages from the page search. Each passage goes in as a document with citations enabled, titled with document and page.
- **Model:** `claude-opus-5-5` at low effort, streamed. Roughly two cents a question at $4 and $20 per million tokens. Claude Haiku 5.5 would be faster and far cheaper; that trade is yours to make.
- **Rules:** answer in three sentences at most, only from the passages, and say "Not in the PDS" otherwise. The page shows only sentences that carry a citation, with the quoted text beside them.
- **Guard:** the box rejects input containing long digit runs or email addresses, and is labelled "no member details".
- **Test set:** 40 questions with known answers from the PDS tables and worked examples. Ask mode stays off until it passes.

**Blocker for Ask mode only:** it sends text to an outside service from a work machine. That needs your employer's AI and data policy to allow it. The lookup works fully without it.

### Done when

- Each of 40 test queries returns the right card in the top three.
- Every card shows document, issue date, page and quote.
- "ttr max" with the TTR chip shows the 10% rule; "min" with age 67 shows 5%.
- Nothing matches silently: an empty result always offers the page search.

### Open questions

- Your team's shorthand for products and processes, for `glossary.local.json`.
- Whether Ask mode is allowed at all.

## 4. "How long will it take?"

**Goal:** one screen answering the most common call question, with the source, and a date calculator.

### Data: `data/timeframes.json`

Each entry: the task, the timeframe, when the clock starts, the type (law, PDS, or internal), the source, and a line to say to the member.

**Timeframes already in the PDS set:**

| Task | Timeframe |
|---|---|
| Lump sum from a Flexi Pension | Usually within five business days of the request |
| Pension payments | Fortnightly by every second Friday; all other frequencies by the 28th |
| Quarterly and half-yearly payment months | March, June, September, December; June and December |
| Cooling-off | 14 days from the welcome letter or the fifth business day after opening, whichever is earlier |
| Temporary Accumulation 1 account | Closes at 90 days from the first transfer |
| Complaints | 45 days for super, 30 for advice, 90 for death benefit objections after the 28-day objection window |
| Transfer balance cap excess | 60 days for the fund to act on an ATO notice |
| Downsizer contribution | Generally within 90 days of settlement |
| Insurance without health evidence | 180 days from starting with an eligible employer; 180 days from default cover starting for top-up |
| Default cover start | Needs an employer contribution within 180 days |
| Notice of intent | Before the tax return is lodged or the end of the next financial year, whichever is first |
| Contribution splitting | By 30 June of the year after the contributions |
| Lapsing binding nomination | Three years from signing, confirming or amending |
| Contributions after 75 | Up to 28 days after the end of the month of the 75th birthday |
| Inactive low-balance transfer to the ATO | 16 months inactive and under $6,000 |
| Departed temporary resident | Six months to claim from the fund |
| Fee increases | 30 days' written notice |
| Transfers out | Up to eight in any 12 months |
| Retirement Bonus | 12 months' continuous membership to qualify; clawback window of 12 months |

**Not in the PDS, so entered by you** in `timeframes.local.json` (git-ignored): processing times for rollovers in and out, pension applications, hardship, death and insurance claims, and contribution allocation.

### Calculators on the same screen

- **Business days:** "received today, five business days" gives a date, skipping weekends and Victorian public holidays.
- **Days from a date:** 14, 28, 90 and 180 days, and three years.
- **Next pension pay date** for each frequency.
- **Deadline this year:** days left to 30 June.

### Done when

- Every PDS timeframe above is present with a page reference.
- The business-day calculator matches a hand count across a public holiday.
- Internal entries are visibly marked as internal and never leave the local file.

### Open questions

- The fortnightly pay cycle anchor date (same as plan 1).
- Which internal processing times you are comfortable keeping in a local file.

## 5. Plain-English explainers (three per concept)

**Reading of the brief:** each concept gets three versions, so you can pick one or try another when the first does not land. If you meant three explainers per product, the list below regroups easily.

### The three versions

| Version | Length | Use |
|---|---|---|
| One-liner | About 10 seconds | The member only needs the gist |
| Walk-through | About 30 seconds | The member needs the steps or the reason |
| Worked example | Numbers or an everyday comparison | The member says "I still don't follow" |

Each concept also carries: the source page, a "stay general" note marking where personal advice would begin, and a handover line to UniSuper Advice on 1800 823 842.

### Concept list (22)

- **Pension:** minimum drawdown; first-year pro-rata; TTR compared with Retirement Phase; the TTR 10% maximum; why money cannot be added to a pension; transfer balance cap; Retirement Bonus; drawdown order; the temporary Accumulation 1 account; the $10,000 close-out.
- **Contributions:** concessional and non-concessional; notice of intent; contribution splitting; carry-forward; bring-forward.
- **Access and tax:** preservation age and conditions of release; taxable and tax-free components.
- **Beneficiaries:** binding, non-binding and reversionary; lapsing and non-lapsing.
- **Insurance and account:** when default cover starts; why unitised cover reduces with age; inactive low-balance accounts.

### Sample: first-year pro-rata

- **One-liner:** "Because your pension started part-way through the year, this year's minimum is only for the days from your start date to 30 June."
- **Walk-through:** "The government sets a minimum you must take each year, as a percentage of your balance based on your age. A full year's minimum assumes twelve months. Your pension started on 1 October, so we only count the days from then to 30 June, and round to the nearest ten dollars. From 1 July it resets to a full-year amount based on your balance that day."
- **Worked example:** "Take someone aged 67 starting with $500,000 on 1 October. A full year would be 5 per cent, so $25,000. There are 273 days left out of 365, which brings it to $18,700."
- **Stay general:** explain how the minimum is worked out; do not suggest how much to draw.
- **Source:** Flexi Pension PDS, "Your income payments".

### Steps

1. Draft all 66 explainers from the PDS text.
2. You edit the wording to match how you speak on calls.
3. Check every number against `rates.json` automatically at build time, so a rate change flags the explainers that quote it.
4. Add to the companion page with search and a copy button.

### Done when

- All 22 concepts have three versions, a source and a stay-general note.
- No explainer contains a figure that is missing from `rates.json`.
- None recommends an amount, a product or a strategy.

## Build order

1. **Drawdown workbook.** Stands alone, and the PDS worked examples prove it.
2. **Shared groundwork, then timeframes.** The smallest data set, and it proves the page-citation pattern.
3. **Forms finder.**
4. **Rule lookup.** The largest piece; reuses the page index and glossary.
5. **Explainers.** Content-heavy; links into the rule cards.
6. **Ask mode**, only if policy allows.

## Upkeep

A new PDS means: run the fetch script, read the change report, update `rates.json`, rebuild. The insurance changes that take effect on 28 November 2026 are the first real test of this.
